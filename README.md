# SEL Check-in 導航員 · 鹿場國小 3 小時教師工作坊

一個自帶簡報與遊戲的單一網站。沒有任何後端、沒有外部套件、不蒐集個資，
所有互動都在使用者自己的裝置上執行。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁版簡報（56 頁，Mindset·Skillset·Toolset 三層架構，含內建計時器與 QR 產生器） |
| `g1.html` | 關卡① 情緒顏色分組（學員 Check-in／主持人分組器／班級溫度統計） |
| `g2.html` | 關卡② 手勢默契挑戰（16 題，三個回合，含錯題回顧與成績卡） |
| `assets/` | 圖片、共用樣式、QR 產生器 |

## 部署到 GitHub Pages

1. 到 <https://github.com/cyysongyy> → **New repository** → 命名為 **`sel-checkin`** → Public → Create。
2. 進入 repo → **Add file ▸ Upload files** → 把 `index.html`、`g1.html`、`g2.html`、`README.md`
   以及整個 **`assets` 資料夾**一起拖進去 → Commit。
3. **Settings ▸ Pages** → Source 選 `Deploy from a branch` → Branch: `main` / `(root)` → Save。
4. 約 1 分鐘後網址即為：`https://cyysongyy.github.io/sel-checkin/`

> 簡報裡的 QR Code 是**依照目前網址即時產生**的，所以 repo 取什麼名字都不會失效；
> 換成別的網域或子資料夾也一樣正確。

## 現場操作

- **翻頁**：鍵盤 `←` `→` 或空白鍵；手機左右滑動；`M` 開目錄。
- **計時器**：點右上角 `⏱` 開始／暫停，**雙擊歸零**。旁邊會顯示目前段落。
- **全螢幕**：右下角 `⛶`。
- **分組組數**：預設 6 組。要改成別的組數，把關卡①的網址加上參數，例如
  `g1.html?g=8`（8 組）。簡報第 5 頁的 QR 會自動跟著改。
- **列印**：直接 `Ctrl/⌘ + P`，會把 56 頁攤平成可列印版本。
